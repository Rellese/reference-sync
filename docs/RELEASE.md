# Подготовка и упаковка

Проверено по документации Eagle 2026-09-17:
[подготовка](https://developer.eagle.cool/plugin-api/publishing/prepare),
[упаковка](https://developer.eagle.cool/plugin-api/publishing/package),
[безопасность](https://developer.eagle.cool/plugin-api/plugin-review/criteria/security-and-privacy),
[визуальные материалы](https://developer.eagle.cool/plugin-api/plugin-review/criteria/visual-assets).

## Состав

В пакет входят только manifest.json, index.html, js/, styles/, assets/,
README.md, CHANGELOG.md и документы docs/. Шрифты распространяются со своими
лицензиями. Макеты Full_design, Git, тесты, история задач, runtime, cookies,
логи, архивы и пользовательские медиа в пакет не входят. devTools отключены.

## Чистая сборка для разработчика

Ветка подготовки: `release/v1.2.0-preparation`.
Команда `npm run prepare:release` создаёт новый каталог в `dist/` и отдельный
список файлов с SHA-256. Берутся только отслеживаемые Git файлы из разрешённых
каталогов. Проверяются локальные импорты, ресурсы, формат WOFF2, лицензии и
отключённые devTools. Символические ссылки отвергаются. Скрипт не удаляет
существующие каталоги и не включает файлы вне списка.

## Выпуск в Eagle

1. Импортируйте подготовленную чистую папку как локальный проект Eagle.
2. Откройте панель плагинов, нажмите правой кнопкой ReferenceSync и выберите
   «Упаковать плагин» / “Pack Plugin”.
3. Выберите место сохранения файла `.eagleplugin`.
4. Установите именно полученный файл и выполните сценарии REVIEW.md
   на Windows и macOS. Обычный ZIP, переименованный в `.eagleplugin`, не подходит.
5. Подготовьте реальные снимки интерфейса без персональных данных, описание
   доступных функций и ограничений, сведения о gallery-dl/Python и данных.
   Для каждого языка публикации нужны полноценные описание и обложка.
6. В Plugin Center выберите отправку плагина, загрузите пакет и заполните
   описание, изменения и ссылку поддержки. Учётные данные модератору, если
   потребуются, передавайте только через закрытую форму подачи.

Подготовленная папка и успешные автоматические тесты не означают прохождение
модерации. Этот документ не утверждает, что Eagle одобрит плагин.
