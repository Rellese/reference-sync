# ReferenceSync для Eagle

Перенос сохранённых публикаций в библиотеку Eagle: выбор материалов,
папки, карусели, имена и описания, нумерация и защита от повторного импорта.

**Версия 1.6.1 — кандидат с Threads; оставшиеся проверки указаны в docs/REVIEW.md.**
Доступные источники: Instagram, Pinterest, Behance, Vimeo, X, Dribbble, Layers, Threads. Для Behance реализованы доски
аккаунта, ссылки на кейс/коллекцию/профиль, полный .rscase и отдельные блоки.
Ранее записана живая проверка трёх проектов, включая встроенные видео; новый
экспортированный пакет на обеих ОС проверяется отдельно.
Интерфейс: русский, English, Français, Español, 中文.

В первом шаге доступен отдельный сценарий **«Понравившиеся публикации»**:
Instagram, Behance (Appreciations), Vimeo, X, Dribbble, Layers и Threads. Он читает
лайки вашего аккаунта в выбранном браузере; папки и архив скрыты. Режимы
«все», «только новые», «последние N» и Stop Link работают в этой ленте.
Импортированные файлы общие с сохранёнками, границы поиска раздельные.
Pinterest не предлагает историю сердечек: реакции и звёздочка избранного
на доске не равны отдельной ленте лайков. Vimeo Likes совпадает с Favorites,
который ранее выбран по умолчанию для сохранёнок; эта настройка сохранена.
Dribbble может возвращать проверку доступа HTTP 202: откройте сайт в выбранном
профиле, затем повторите. Полнота истории зависит от данных, доступных сайту.

## Установка тестовой версии

1. Откройте Eagle → «Плагин» → «Параметры разработчика…» →
   «Импортировать локальный проект».
2. Выберите папку ReferenceSync, внутри которой лежит `manifest.json`.
3. В меню «Плагин» откройте ReferenceSync.
4. Если движок не готов, нажмите «Подготовить движок». Плагин использует
   подходящий Python с pip либо скачает отдельный переносимый Python с проверкой
   SHA-256; затем установит загрузчики и видеокомпоненты. Терминал, отдельная
   установка Python и права администратора не нужны. Системный Python/PATH
   не меняются. Windows ARM64 требует Windows 11 с поддержкой запуска x64.
   Установка начинается только по кнопке; закрытие отменяет подготовку.

## Первый перенос

1. Выберите «Скачивание ваших сохранённых». Войдите в нужную соцсеть в браузере. В плагине выберите этот браузер
   и профиль. Аккаунт определяется по выбранной сессии.
2. Выберите режим поиска. «Найти только новые» останавливается на уже
   импортированной публикации; «Проверить все сохранённые» проходит весь список.
   «Проверить только последние» дополнительно ограничивает число результатов.
3. При необходимости включите выбор папок и «Остановиться по ссылке».
   Поиск прекращается на первой достигнутой границе; сама граница исключается.
4. Нажмите «Начать поиск». Выберите папки, затем публикации и элементы каруселей.
5. Настройте имена и описания. Запустите импорт и выберите папку Eagle.
6. Дождитесь итога. При остановке повторно откройте плагин и используйте
   предложенное восстановление незавершённого задания.

Режим «Из архива» для Instagram/Pinterest/Threads принимает поддерживаемые ZIP/JSON/HTML.
Для Threads проверен настоящий экспорт Meta: полный ZIP читает только
`saved_threads.json`. Лайки, собственные публикации и данные профиля из этого
ZIP не добавляются в сохранёнки. Можно также выбрать отдельный JSON или HTML.
В Центре аккаунтов Meta выберите профиль Threads, категорию «Threads» и JSON.
Списки сохранёнок содержат ссылки; для получения медиа нужен выбранный профиль
браузера с выполненным входом в Threads.
Для Behance, Vimeo, X, Dribbble и Layers совместимый архив сохранённого не подтверждён, поэтому этот режим скрыт.
Исходный архив не изменяется. Архивы, содержащие только ссылки, требуют сети
и, при необходимости, выбранной браузерной авторизации.

## Threads

Выберите профиль браузера, в котором открыт Threads. Сохранёнки и понравившиеся
публикации — отдельные сценарии первого шага. Поддерживаются фото (включая HEIC),
видео, смешанные карусели и выбор отдельных компонентов. Название берётся из первой
строки текста публикации, описание — из её текста. По ссылке загружается
отдельный пост; поддерживаются threads.com и прежние ссылки threads.net.

«Последние N» проверяет максимум N уникальных публикаций; текстовые посты
без фото/видео пропускаются и отмечаются в журнале. «Все» проходит доступные
страницы, «Только новые» останавливается на импортированной публикации.
Папки не используются. Ответы и следующие посты ветки не подменяют карусель
исходной публикации. Для медиа Saved/Link/Likes сохраняется общий ID, чтобы
повторное добавление не создавало отдельный экземпляр.

Внутри Eagle с Chrome полный поиск проверил 324 публикации: 316 с медиа,
7 текстовых без медиа, 1 исходно с ошибкой HEIC. После исправления по её
ссылке подтверждены все 6 компонентов (5 HEIC и видео). Проверены
последние 2, границы истории/Stop Link, последние 22 понравившиеся
(с пагинацией) и прямая ссылка. Распознаны 27 смешанных каруселей; скачаны изображение
и видео, видео полностью проверено декодированием. Настоящий ZIP дал 324
сохранённые ссылки; две разрешились через браузерную сессию. Добавление Threads
в библиотеку, скачивание всей смешанной карусели, другие браузеры и Windows
ещё требуют проверки; это не moderation-ready релиз.

## Layers

Без выбора папок поиск идёт по **всем сохранённым коллекциям** вошедшего
аккаунта; при выборе — только по указанным коллекциям. Likes, Explore, свои
публикации и списки дизайнеров не используются как сохранёнки. Пустой каталог
остаётся пустым. Поддерживаются HTTPS-ссылки на работу, коллекцию и профиль
(его публичные коллекции), включая ссылки с названием после ID.

У работы Layers одно медиа: изображение, GIF или видео; карусельный фильтр
скрыт. Название берётся из названия работы, описание — из её описания, автор
остаётся отдельным полем. Полный поиск объединяет повторы с сохранением всех
коллекций. Поиск новых прекращается на известном ID, последние N дополнительно
ограничивают выдачу; Stop Link исключает саму границу. Без выбора папок N —
общий предел уникальных работ в порядке коллекций платформы, а не обещанный
глобальный порядок времени сохранения. С выбором папок N/границы независимы.

Сессия выбранного браузера использует приватный временный снимок только
cookies Layers. HTTPS-запросы только читают данные; CSRF и сведения аккаунта
не пишутся в журнал. Медиа скачиваются с проверенных собственных хранилищ
Layers без cookies браузера, видео проверяется целиком. Расширение и API-ключ
не нужны. Совместимая схема архива сохранённых коллекций не подтверждена:
архивный режим скрыт. [Privacy Layers](https://layers.to/legal/privacy-policy)
описывает запрос доступа к данным, но не готовый импортируемый архив коллекций.
Нативный импорт в Eagle, Windows и остальные браузеры требуют отдельной приёмки.

## Dribbble

По умолчанию поиск читает **все сохранённые коллекции** вошедшего аккаунта.
При включённом выборе папок — только выбранные коллекции. Liked Shots и свои
опубликованные работы не подменяют сохранённое. Профиль по ссылке означает
его публичные коллекции; можно также вставить ссылку на коллекцию или шот.

Поддерживаются изображения, GIF, видео и несколько медиа в шоте. Все медиа
имеют базовое название шота. Каждый текстовый блок относится только к медиа
непосредственно выше; следующие абзацы дополняют его описание. Вводный текст
до первого медиа остаётся в метаданных публикации, а не размножается на файлы.
Пустое описание компонента не заменяется общим текстом шота. Дополнительные
описания, нумерация и ручные правки применяются обычным способом.

Все три режима и Stop Link действуют на сохранённых коллекциях. Без выбора
папок последние N — общий предел уникальных шотов в порядке коллекций Dribbble,
а не гарантированный глобальный порядок времени сохранения. При выбранных
папках N и границы применяются отдельно к каждой коллекции. Полный поиск
объединяет повторяющиеся шоты и сохраняет все папочные вхождения.

Совместимый архив сохранённых коллекций не подтверждён; архивный режим скрыт.
[Privacy Dribbble](https://dribbble.com/privacy) описывает запрос данных без
подтверждённой схемы архива сохранёнок.
[Официальный API v2](https://developer.dribbble.com/v2/shots/) показывает собственные шоты пользователя, поэтому для
сохранённого читаются страницы Dribbble через защищённую сессию браузера.
Скрипты страниц не выполняются; изображения и предложенные сайтом видео
скачиваются с HTTPS-CDN без cookies. Расширение и ключ API не нужны.
Нативный импорт в Eagle, Windows и остальные браузеры требуют отдельной приёмки.

## X (Twitter)

Войдите в X в выбранном браузере и профиле. По умолчанию поиск идёт по всем
закладкам **Bookmarks**. Поиск по папкам читает именно выбранные папки закладок;
для них требуется X Premium. Фотографии, видео, анимированные GIF (MP4) и
несколько медиа одного поста поддерживаются. Текст сохраняется как описание.
Текстовые закладки без медиа учитываются в лимите последних N, но не создают
пустых элементов Eagle. Повторы между папками сохраняют все папочные вхождения.

Режимы: весь список, до ранее импортированного поста, последние N в каждой
выбранной папке с той же границей. Stop Link исключает саму публикацию.
По ссылке поддерживается отдельная HTTPS-публикация X/Twitter; поиск медиа
произвольного профиля не добавлен. Likes доступен отдельным сценарием первого шага. Архив X существует, но схема экспорта
закладок не подтверждена: архивный режим X скрыт.

Расширение браузера и ключи API не требуются. Используется текущий веб-интерфейс
X через установленный gallery-dl; его изменения или ограничения аккаунта могут
потребовать обновления. Плагин не изменяет публикации, лайки и закладки.
Cookies X остаются в защищённом временном снимке. Медиа скачиваются с
pbs.twimg.com/video.twimg.com по HTTPS без браузерных cookies; видео полностью
проверяется FFmpeg. При 429, остановке или нехватке места очередь прекращается.
Живая проверка macOS Chrome и загрузка видео выполнены вне личной библиотеки;
нативный импорт Eagle, Premium-папки и другие браузеры/Windows требуют приёмки.

## Vimeo

Войдите в Vimeo в выбранном браузере и профиле. Без поиска по папкам источник
читает **Favorites — понравившиеся видео**. С выбором папок доступны также
**Watch Later** и подборки **Showcases**, возвращённые аккаунтом Vimeo.
Свои папки загрузок Library не являются коллекциями чужих сохранённых видео
и в этот список не включены. Одно видео — одна публикация; каруселей нет.

Три режима работают независимо в каждой папке: полный список, до известного
видео, последние N с границей известного видео. Stop Link исключает само видео
и всё после него. Повторы между папками объединяются, их вхождения сохраняются.
Поддерживаются HTTPS-ссылки на видео и Showcase; авторские ссылки из API
приводятся к проверенному ID, а приватный hash сохраняется. Архивный сценарий
скрыт: совместимая схема экспорта Favorites/подборок не подтверждена.

Загрузка использует yt-dlp из подготовленного движка; файл проверяется полностью
через FFmpeg до импорта. Доступ определяется выбранным аккаунтом; DRM,
покупка доступа, прямые трансляции и собственные upload-папки не поддерживаются.
Запросы и перенаправления — только HTTPS. HTTP 429 останавливает очередь.
Pause проверяется между запросами и при передаче фрагментов; Stop отменяет
процесс. При заполнении диска загрузка прекращается, подтверждённые файлы Eagle
не удаляются. Предварительная проверка свободного места не резервирует диск.

Проверено 2026-10-11 на macOS/Chrome: вход, Favorites N=15, Watch Later,
граница известного видео, отдельная ссылка и скачивание с полным декодированием.
В текущем аккаунте API не вернул Showcases: непустой список проверен на фикстуре.
Снимки cookies/видео теста удалены; данных аккаунта в репозитории нет.
Нативный импорт Vimeo в Eagle, Windows и другие браузеры требуют приёмки.

## Предварительная проверка Behance (M7)

1. Выберите Behance и сценарий в первом шаге.
2. Для сохранённых выберите браузер и профиль с выполненным входом.
   Аккаунт Behance определяется автоматически; никнейм вводить не нужно.
   После «Начать поиск» выберите доски настроения. Выбранный тип поиска
   применяется отдельно к каждой доске.
3. Для конкретного кейса или профиля выберите «Скачивание по ссылке» и вставьте
   URL в поле «Ссылка на пост/профиль». Никнейм здесь не требуется. Ссылки
   `/moodboard/…` и `/collection/…` тоже поддерживаются.
4. Кнопка «Блоков» открывает выбор отдельных медиа. Для небольшой проверки
   оставьте одно изображение/GIF, запустите импорт и выберите тестовую папку Eagle.
   Затем отдельно проверьте видео.

Режим ссылок также подключён к Instagram и Pinterest. Выбор браузера сохранён
для контента, требующего входа. Настройки поиска сохранённых не ограничивают
поиск по ссылке. Текстовые блоки отдельно не импортируются.
Сохранение кейса целиком и второй плагин-просмотрщик — следующие этапы.

Реальный поиск проверен на Citadel Narrative Sequence Design (36 медиа)
и Animation Portfolio 2024 (69 медиа). Скачаны JPG, GIF и MP4; проверка импорта
в Eagle ещё требуется. Ошибка 403 при чтении этих кейсов исправлена.
Выбранное встроенное видео Vimeo во втором кейсе также скачано после обновления
видеокомпонента. Если плагин предложит «Скачать» для подготовки видео, нажмите
эту кнопку и повторите импорт. Все внешние плееры пока не подтверждены.

Сессия Behance готовится только на время операции: плагин обрабатывает известную
проверку сайта без исполнения его скриптов. Временные cookies удаляются после
завершения, ошибки или остановки, исходный профиль браузера не изменяется.

## Зависимости и данные

Движок [gallery-dl](https://github.com/mikf/gallery-dl) запускается отдельным
процессом. По кнопкам «Скачать»/«Обновить» Python и pip устанавливают его
и видеокомпоненты yt-dlp с curl_cffi (совместимость с браузерами)
и FFmpeg (пакет imageio-ffmpeg) из PyPI в личную папку плагина; это загрузка и выполнение стороннего кода.
При отсутствии pip может запускаться встроенный в Python ensurepip.
Движок и Python не включены в пакет плагина.

Плагин использует авторизацию выбранного профиля браузера, чтобы обратиться
к выбранной соцсети. Пароль в плагин вводить не нужно. Pinterest использует
временный файл cookies, удаляемый после операции; при аварийном завершении
удаление не гарантируется. Настройки, история импорта и незавершённые задания
хранятся локально. Подробности: [данные и подключения](docs/PRIVACY.md).

## Если возникла ошибка

- Проверьте вход в выбранном профиле браузера и доступность соцсети.
- При ограничении запросов дождитесь снятия ограничения и используйте
  безопасную скорость. Повторные частые запросы не помогают.
- Откройте «Показать технический журнал». Перед отправкой уберите имена
  аккаунтов, пути к личным файлам и любую авторизацию.
- Поддержка: [Issues проекта](https://github.com/Rellese/reference-sync/issues).
  Не публикуйте cookies, пароли, личные архивы или полный профиль браузера.

## Временные файлы больших Behance-импортов

После сборки каждого `.rscase` плагин проверяет CRC всех вложений и наличие
исходных медиа в архиве, сохраняет состояние, затем удаляет исходники, не
выбранные для отдельного импорта. Готовые кейсы накапливаются и добавляются
в Eagle после скачивания всей очереди. Выбранные отдельные блоки сохраняются
до импорта. При нехватке места очередь останавливается; готовые файлы остаются.
Сборка и импорт проверяют место с резервом 2 ГиБ. Это проверка в момент операции,
не резервирование диска: другие программы тоже могут занять свободное место.
При физических копиях пик составляет около двух объёмов готовых кейсов плюс
текущий кейс, выбранные отдельные блоки и служебный запас.
