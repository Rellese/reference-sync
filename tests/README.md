# ReferenceSync tests

Тесты защищают изолированную логику плагина до рефакторинга.

## Что проверяется сейчас

- распознавание сетевых ошибок;
- остановка длительной операции;
- базовый контракт реестра источников.

## Ограничения

Эти тесты не доказывают, что работают:

- Instagram;
- cookies браузера;
- gallery-dl;
- скачивание файлов;
- импорт в Eagle;
- восстановление задания;
- интерфейс.

Для этих функций потребуются отдельные integration и live tests.

## Безопасность

В репозиторий нельзя добавлять cookies, токены, личные архивы,
скачанные публикации и другие пользовательские данные.

## Запуск

GitHub автоматически запускает тесты после отправки изменений.
Пользователю не требуется терминал.


## Регрессии интерфейса M1-T09Z

`tests/browser/selection.test.cjs` проверяет реальный интерфейс в Chromium:
выбор всех строк на обоих этапах, Shift по порядку дерева, независимый выбор
подпапок, промежуточное состояние папок, копии постов, карусели, Undo,
отложенную проверку стоп-ссылки и точные цвета подсказки/ошибки.

GitHub запускает этот набор отдельно от unit-тестов. Playwright 1.62.1 и
Chromium устанавливаются только в окружение проверки, в плагин они не входят.
Локальный запуск для разработчика с доступным Playwright:

```sh
node --test tests/browser/selection.test.cjs
```

Можно указать `BROWSER_CHANNEL=chrome` для установленного Chrome.
Создаётся отдельный временный профиль. Сервер слушает только `127.0.0.1`;
внешние запросы страницы блокируются. Данные публикаций вымышленные.
В тестовом HTTP-ответе открывается доступ к существующему выбору папок;
production-файлы ради теста не изменяются. Проверки не подтверждают работу
реальных cookies, gallery-dl, поиска и импорта в Eagle.
