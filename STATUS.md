# Известные риски

1. Постоянный реестр импортированных публикаций отсутствует или не подключён.
2. После перезапуска возможен повторный импорт.
3. Незавершённое задание не имеет подтверждённого восстановления.
4. Выбор папки Eagle не подключён к импорту.
5. Проверка созданного элемента Eagle не подтверждена.
6. `main.js` не использует единый source adapter для основного сценария.
7. `instagram.js` и `gallery-source.js` содержат дублирующуюся логику.
8. Непроверенные источники ошибочно помечены как готовые.
9. README и HANDOFF противоречат текущей архитектуре.
10. До живого запуска нельзя утверждать, что Instagram работает.

# Следующая задача

## M0-T06 — подготовить безопасную структуру тестов

Цель:

Создать минимальную тестовую защиту до изменения или удаления production-кода.

План:

1. определить тестовый способ, не требующий Eagle для простых проверок;
2. создать папки для unit-тестов и обезличенных fixtures;
3. не добавлять cookies, архивы и личные данные;
4. добавить тесты только для изолируемой логики;
5. проверить, что тестовые файлы не попадают в release;
6. не менять поведение Instagram;
7. обновить `.gitignore` только необходимыми безопасными правилами;
8. зафиксировать отдельный коммит.

Не входит в M0-T06:

- исправление Instagram;
- удаление skeleton-модулей;
- изменение дизайна;
- добавление социальных сетей;
- живое тестирование Eagle;
- глобальный рефакторинг.
