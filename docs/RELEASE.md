# Подача ReferenceSync 1.0.0 — 2026-10-21

Чистовая папка содержит рабочий плагин, шрифты с лицензиями и необходимые
инструкции. Git, тесты, дизайн, архивы аккаунтов, cookies, runtime, диагностические
логи и старые сборки в неё не включаются. Файлы сверяются по SHA-256.

Версия 1.0.0 задана владельцем для первой публичной подачи. История разработки
сохранена в Git. Подготовленная папка не является экспортированным .eagleplugin.
