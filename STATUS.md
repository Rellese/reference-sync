# Результат M1-T01

Проверена цепочка:

`discovery → normalization → download target → failure classification`

Подтверждено:

- Python и JS используют URL публикации как download target;
- внутренний `/api/v1/media/.../info/` вызывает `gallery-dl`;
- неправильное формирование media ID в JS не подтверждено;
- Instagram вернул настоящий `400 Bad Request`;
- интернет-соединение при этом не пропадало.

Подтверждённые расхождения Python и JS:

1. Python распознаёт сеть по точным шаблонам, включая `ssl error`.
2. JS использует слишком широкое слово `ssl`.
3. `NotOpenSSLWarning` поэтому ошибочно считается обрывом связи.
4. Python классифицирует обычный `400` как `COMMAND_ERROR`.
5. JS запускает для него лестницу сетевых повторов.
6. Python создаёт один защищённый cookie snapshot на пачку.
7. JS повторно читает cookies браузера при каждой попытке.

Решение:

Сначала создать обезличенные regression tests, затем отдельно
исправить классификацию и продолжение очереди.

Cookie snapshot переносить отдельной задачей после восстановления
корректной обработки ошибок.

Цель:

1. успешные элементы до ошибки сохраняются;
