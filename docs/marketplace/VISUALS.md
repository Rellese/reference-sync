# ReferenceSync — visual brief

Inspected 2026-10-05: Figma Reference Sync → «Этапы», two covers and eight supporting frames. No Figma/store assets were changed.

## Required: both localized covers

The current 1560×1040 covers shrink a dense dark full-window screenshot into the center. At 400 px wide, source icons, import action and essential interface text cannot be read. The orange identity can stay.

Use a bright headline **Saved references → Eagle** / **收藏参考素材，导入 Eagle**, a large real crop of Instagram/Pinterest/Behance selection, a readable **Download and add to Eagle** / **下载并添加到 Eagle** control and an Eagle result grid. Connect selection → review → result with an arrow. Use current screenshots after reordering sources. Make the complete interface secondary, if retained at all.

Check each locale independently at 300–400 px wide; this is a recommended practical check, not an official mandatory size. The official template is optional.

## Supporting slides: recommended, not explicitly required by the letter

| Pair | Revision | Suggested EN / 简体中文 heading |
| --- | --- | --- |
| 0-5: Makes downloading EASIER / 让下载更轻松 | Large source crop, 3–4 selected rows, Eagle result. Avoid another dense full-window screenshot. | Choose. Review. Import. / 选择、检查、导入 |
| 1: Several search modes / 多种搜索模式 | Enlarge the three modes and limit field; reduce unrelated table. | New, all, or latest posts / 新帖子、全部收藏或最近帖子 |
| 2: Flexible settings / 灵活的设置 | Large media selection and one before/after filename; avoid several tiny panels. | Pick media and control names / 选择媒体，自定义名称 |
| 3: CONTROL the download process / 控制下载过程 | Large progress, pause/stop, completion and Eagle result. | Track progress and stop safely / 查看进度，随时停止 |

All eight have dark low-contrast headings. Make headings and focal controls bright; use metallic treatment for decoration only. Chinese needs a separate spacing check. Supporting frames are 1560×978 while covers are 1560×1040; different ratios alone are not a documented rejection reason. Inspect upload cropping.

Use actual controls with crops/callouts, not fake functionality. Use media you may show publicly; remove private profiles, email addresses, paths, logs and offensive tags.
