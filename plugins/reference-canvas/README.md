# ReferenceCanvas 0.2.0

Отдельный просмотрщик кейсов ReferenceSync для Eagle. Тестовая версия: проверена
в Chrome и автоматических тестах; установка и просмотр непосредственно в Eagle,
а также Windows пока не подтверждены.

## Установка для предварительной проверки

1. Сохраните папку ReferenceCanvas целиком в постоянное место.
2. В Eagle откройте меню «плагин» → «Параметры разработчика…» →
   «Импортировать локальный проект».
3. Выберите папку, внутри которой лежит `manifest.json` этого просмотрщика.
4. В ReferenceSync выберите Behance, откройте настройки блоков кейса и включите
   «скачать кейс целиком». Скачайте и импортируйте кейс.
5. Откройте полученный элемент `.rscase` в Eagle двойным щелчком.

Это расширение формата файла: отдельного окна запуска ReferenceCanvas в меню
обычных плагинов может не быть. Оно предназначено для открытия `.rscase`.
ReferenceSync и ReferenceCanvas устанавливаются отдельными папками.

## Просмотр

- Изображения, GIF, локальные видео и текст следуют порядку блоков кейса.
- Колёсико прокручивает полотно; Ctrl/Cmd + колёсико меняет масштаб.
- Центральный ползунок меняет масштаб; нажатие на процент возвращает вид по ширине.
- Мини-карта справа внизу показывает положение на полотне. Нажмите или потяните
  её, чтобы перейти к другой области; когда весь кейс помещается, она скрывается.
- Цвет фона выбирается из темы, которую Eagle передаёт при открытии кейса:
  тёмная, серая, синяя, фиолетовая, светлая, светло-серая; автоматический режим
  следует системной теме. При смене темы Eagle переоткройте кейс, если фон не обновился.
- Потяните свободную область полотна мышью, чтобы переместить его.
- У видео собственные кнопки воспроизведения; ссылки открываются по нажатию.
- Недоступные и неподдерживаемые блоки показаны отдельными плашками.
- Интерфейс поддерживает русский, английский, французский, испанский и китайский.

Обложка берётся из локального изображения кейса. Если Eagle не умеет декодировать
его формат или изображения нет, используется логотип. Поддержка видеокодеков
зависит от версии Eagle и системы: расширение файла само по себе не гарантирует
воспроизведение. Удаление и отдельный экспорт блоков появятся в M7-T07.

## Файлы и ограничения

Читается `.rscase` v1, создаваемый ReferenceSync: ZIP без сжатия, до 2 ГиБ − 1 байт,
до 10 000 файлов. Произвольные ZIP и другие версии формата не поддерживаются.
Сначала читается только структура кейса. Медиа извлекаются по мере приближения
к видимой области, порциями во временную папку; при закрытии она удаляется.
Большой отдельный файл всё ещё требует времени на чтение и проверку CRC.
Мини-карта отображает доступные превью; ещё не загруженные блоки показаны схематично.
При аварийном завершении Eagle временная папка может остаться в системном temp.
Исходный кейс при просмотре не изменяется. Требуется свободное место для его медиа.

Просмотр не загружает удалённые страницы, не исполняет HTML/JavaScript из кейса
и не использует браузерную сессию. Внешняя ссылка открывается только по нажатию.
ZIP проверяется на CRC, недопустимые пути, повторения и ограничения размера.

## Разработка и выпуск

Папка самодостаточна, установка зависимостей и сборка не нужны. Для чистого пакета
копируются `manifest.json`, `package.json`, `assets/`, `lib/`, `thumbnail/`,
`viewer/`, `README.md`, `STATUS.md`. Тесты расположены в корне репозитория:
`tests/unit/reference-canvas.test.js` и `tests/browser/reference-canvas.test.cjs`.

Не включать логи, тестовые кейсы, скачанные медиа, временные файлы и `.git`.
Перед экспортом через Eagle проверить реальный кейс на macOS и Windows.
Эта версия ещё не готова к отправке на модерацию.

## Репозиторий

Отдельное зеркало просмотрщика: https://github.com/Rellese/reference-canvas
(закрытый репозиторий владельца). Исходная разработка и совместные тесты находятся
в `plugins/reference-canvas/` репозитория https://github.com/Rellese/reference-sync.
В зеркало публикуется только эта папка через `git subtree split`, без остальных
файлов ReferenceSync. Это сохраняет одинаковый код в обоих репозиториях.
Правки следует вносить в исходную папку и затем обновлять зеркало.
