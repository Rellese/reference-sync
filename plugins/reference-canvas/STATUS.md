# ReferenceCanvas — состояние проекта

Обновлено: 2026-09-28. Версия: 0.1.0. Этап: M7-T06.
База ReferenceSync: `1f7955d`. Статус: implemented / fixture-tested.

- [x] Самостоятельный preview plugin для `.rscase`, thumbnail и viewer.
- [x] Ограниченный ZIP-reader с CRC, безопасными путями, отменой и очисткой temp.
- [x] Полотно с изображениями, текстом, GIF, видео и явными ссылками.
- [x] Масштаб, перемещение, плашки недоступных блоков, пять языков.
- [x] Unit-проверки чтения, повреждений, manifest, отмены и fallback-thumbnail.
- [x] Chrome: настоящий архив, изображение, текст, ссылки, масштаб, перемещение;
  отдельно подтверждены декодирование GIF и воспроизведение тестового MP4.
  Мост Node/Eagle в браузерном тесте подставной.
- [ ] Реальный Eagle: регистрация формата, thumbnail через nativeImage, открытие
  кейса и очистка после закрытия. Попытка установки остановилась на заблокированном Mac.
- [ ] Windows, большие реальные кейсы, совместный импорт двух режимов.
- [ ] M7-T07: экспорт и удаление блоков с атомарной перезаписью кейса.

Следующее действие: после разблокировки Mac завершить импорт локального проекта
в Eagle, открыть тестовый `.rscase` и проверить обложку, GIF/видео, масштаб и ссылки.
Затем проверить официальный путь экспорта отдельного блока (format plugin
не предоставляет обычный Eagle Plugin API). Не отмечать живую проверку выполненной
на основании браузерных тестов.
