# ReferenceSync для Eagle

Перенос сохранённых публикаций в библиотеку Eagle: выбор материалов,
папки, карусели, имена и описания, нумерация и защита от повторного импорта.

**Версия 1.0.1 — обновление для проверки перед отправкой в Eagle.**
Instagram — основной сценарий. Pinterest и чтение архивов доступны для
тестирования. Dribbble, Behance, X, Vimeo и Layers пока недоступны.
Интерфейс: русский, English, Français, Español, 中文.

## Установка тестовой версии

1. Откройте Eagle → «Плагин» → «Параметры разработчика…» →
   «Импортировать локальный проект».
2. Выберите папку ReferenceSync, внутри которой лежит `manifest.json`.
3. В меню «Плагин» откройте ReferenceSync.
4. Если движок не найден, прочитайте условия ниже и нажмите «Скачать».
   При отсутствии Python 3 сначала установите его с [python.org](https://www.python.org/downloads/).
   Плагин не устанавливает Python автоматически.

## Первый перенос

1. Войдите в нужную соцсеть в браузере. В плагине выберите этот браузер
   и профиль. Для Pinterest укажите имя аккаунта.
2. Выберите режим поиска. «Найти только новые» останавливается на уже
   импортированной публикации; «Проверить все сохранённые» проходит весь список.
   «Проверить только последние» дополнительно ограничивает число результатов.
3. При необходимости включите выбор папок и «Остановиться по ссылке».
   Поиск прекращается на первой достигнутой границе; сама граница исключается.
4. Нажмите «Начать поиск». Выберите папки, затем публикации и элементы каруселей.
5. Настройте имена и описания. Запустите импорт и выберите папку Eagle.
6. Дождитесь итога. При остановке повторно откройте плагин и используйте
   предложенное восстановление незавершённого задания.

Режим «Из архива» принимает поддерживаемые ZIP/JSON/HTML-экспорты.
Исходный архив не изменяется. Архивы, содержащие только ссылки, требуют сети
и, при необходимости, выбранной браузерной авторизации.

## Зависимости и данные

Движок [gallery-dl](https://github.com/mikf/gallery-dl) запускается отдельным
процессом. По кнопкам «Скачать»/«Обновить» Python и pip устанавливают его
и видеокомпоненты yt-dlp и FFmpeg (пакет imageio-ffmpeg) из PyPI в личную папку плагина; это загрузка и выполнение стороннего кода.
При отсутствии pip может запускаться встроенный в Python ensurepip.
Движок и Python не включены в пакет плагина.

Плагин использует авторизацию выбранного профиля браузера, чтобы обратиться
к выбранной соцсети. Пароль в плагин вводить не нужно. Pinterest использует
временный файл cookies, удаляемый после операции; при аварийном завершении
удаление не гарантируется. Настройки, история импорта и незавершённые задания
хранятся локально. Подробности: [данные и подключения](docs/PRIVACY.md).

## Если возникла ошибка

- Проверьте вход в выбранном профиле браузера и доступность соцсети.
- При ограничении запросов дождитесь снятия ограничения и используйте
  безопасную скорость. Повторные частые запросы не помогают.
- Откройте «Показать технический журнал». Перед отправкой уберите имена
  аккаунтов, пути к личным файлам и любую авторизацию.
- Поддержка: [Issues проекта](https://github.com/Rellese/reference-sync/issues).
  Не публикуйте cookies, пароли, личные архивы или полный профиль браузера.
