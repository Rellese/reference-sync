# Решение по очистке

До успешного M0-T07 ничего из старого production-кода не удалять.

После baseline можно отдельными небольшими коммитами удалить:

- `HANDOFF.md`;
- `ecosystem.config.cjs`;
- неподтверждённые source adapters;
- неиспользуемый `gallery-source.js`;
- неработающий Layers adapter.

CSS, шрифты и иконки пока сохраняются.

---

# Известные риски

1. Постоянный реестр импортированных публикаций не подтверждён.
2. После перезапуска возможен повторный импорт.
3. Восстановление незавершённого задания не подтверждено.
4. Выбор папки Eagle не подключён к импорту.
5. Проверка созданного элемента Eagle не подтверждена.
6. `main.js` напрямую связан с Instagram и не использует единый adapter.
7. `instagram.js` и `gallery-source.js` содержат дублирование.
8. Непроверенные источники помечены как готовые.
9. README и HANDOFF устарели.
10. Автоматические unit-тесты не заменяют живой запуск Eagle.
