# ReferenceCanvas — состояние проекта

Обновлено: 2026-09-28. Версия: 0.2.0. Этап: M7-T06.
База ReferenceSync: `47aa982`. Статус: implemented / fixture-tested.

- [x] Самостоятельный preview plugin для `.rscase`, thumbnail и viewer.
- [x] Ограниченный ZIP-reader с CRC, безопасными путями, отменой и очисткой temp.
- [x] Полотно с изображениями, текстом, GIF, видео и явными ссылками.
- [x] Масштаб, перемещение, плашки недоступных блоков, пять языков.
- [x] Unit-проверки чтения, повреждений, manifest, отмены и fallback-thumbnail.
- [x] Chrome: настоящий архив, изображение, текст, ссылки, масштаб, перемещение;
  отдельно подтверждены декодирование GIF и воспроизведение тестового MP4.
  Мост Node/Eagle в браузерном тесте подставной.
- [ ] Реальный Eagle: регистрация формата, thumbnail через nativeImage, открытие
  кейса и очистка после закрытия для версии 0.2.0. Первая версия открыта пользователем.
- [ ] Windows, большие реальные кейсы, совместный импорт двух режимов.
- [ ] M7-T07: экспорт и удаление блоков с атомарной перезаписью кейса.

Следующее действие: установить обновлённый локальный проект
в Eagle, открыть тестовый `.rscase` и проверить обложку, GIF/видео, масштаб и ссылки.
Затем проверить официальный путь экспорта отдельного блока (format plugin

## Патчи интерфейса и скорости — 2026-09-28

- [x] M7-T06D — фон без разделительной полосы, шесть палитр Eagle + авто.
- [x] M7-T06E — собственные полосы прокрутки по геометрии Eagle, перетаскивание.
- [x] M7-T06F — мини-карта, видимая рамка, переход и перемещение по кейсу.
- [x] M7-T06G — центральный ползунок и процент; нажатие процента — по ширине.
- [x] M7-T06H — lazy-reader и IntersectionObserver: открытие manifest отдельно
  от медиа, повторный запрос не распаковывает файл ещё раз, отмена очищает temp.
- [x] M7-T06I — создан закрытый `Rellese/reference-canvas`, публикация подпапки.

Проверки: 386 unit-тестов в ReferenceSync; браузерный сценарий Canvas с MP4/GIF,
мини-картой, масштабом, всеми шестью цветами и авто. В тестах мост Eagle подставной.
Измерение чтения локального архива с настоящим MP4 (23 417 208 байт):
полная распаковка до возврата — 166,3 мс; открытие только структуры — 0,44 мс.
Это одиночное измерение reader, не время полной отрисовки в Eagle.

Пользователь подтвердил открытие первой версии скриншотом реального кейса.
Обновлённый интерфейс 0.2.0 пока проверен в Chrome, не в Eagle/Windows.
Темы и размеры сверены с ресурсами установленного Eagle; приватные скрипты Eagle
не используются. После смены темы может потребоваться переоткрыть кейс.
Мини-карта ещё не загруженных блоков схематична. Первое чтение большого видео
не мгновенно. Следующий шаг — живая проверка 0.2.0, затем M7-T07.
