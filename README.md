# ReferenceSync для Eagle

Перенос сохранённых публикаций в библиотеку Eagle: выбор материалов,
папки, карусели, имена и описания, нумерация и защита от повторного импорта.

**Версия 1.0.0 — сборка для первой публичной подачи; оставшиеся проверки указаны в docs/REVIEW.md.**
Доступные источники: Instagram, Pinterest, Behance, Vimeo, X, Dribbble, Layers, Threads. Для Behance реализованы доски
аккаунта, ссылки на кейс/коллекцию/профиль, полный .rscase и отдельные блоки.
Ранее записана живая проверка трёх проектов, включая встроенные видео; новый
экспортированный пакет на обеих ОС проверяется отдельно.
Интерфейс: русский, English, Français, Español, 中文.

В первом шаге доступен отдельный сценарий **«Понравившиеся публикации»**:
Instagram, Behance (Appreciations), Vimeo, X, Dribbble, Layers и Threads. Он читает
лайки вашего аккаунта в выбранном браузере; папки и архив скрыты. Режимы
«все», «только новые», «последние N» и Stop Link работают в этой ленте.
Импортированные файлы общие с сохранёнками, границы поиска раздельные.
Pinterest не предлагает историю сердечек: реакции и звёздочка избранного
на доске не равны отдельной ленте лайков. Vimeo Likes совпадает с Favorites,
который ранее выбран по умолчанию для сохранёнок; эта настройка сохранена.
Dribbble может возвращать проверку доступа HTTP 202: откройте сайт в выбранном
профиле, затем повторите. Полнота истории зависит от данных, доступных сайту.

## Установка

Для установки готового пакета откройте `.eagleplugin` в Eagle.
Для локальной проверки папки проекта:

1. Откройте Eagle → «Плагин» → «Параметры разработчика…» →
   «Импортировать локальный проект».
2. Выберите папку ReferenceSync, внутри которой лежит `manifest.json`.
3. В меню «Плагин» откройте ReferenceSync.
4. Если движок не готов, нажмите «Подготовить движок». Плагин использует
   подходящий Python с pip либо скачает отдельный переносимый Python с проверкой
   SHA-256; затем установит загрузчики и видеокомпоненты. Терминал, отдельная
   установка Python и права администратора не нужны. Системный Python/PATH
   не меняются. Windows ARM64 требует Windows 11 с поддержкой запуска x64.
   Установка начинается только по кнопке; закрытие отменяет подготовку.

## Первый перенос

1. Выберите «Скачивание ваших сохранённых». Войдите в нужную соцсеть в браузере. В плагине выберите этот браузер
   и профиль. Аккаунт определяется по выбранной сессии.
2. Выберите режим поиска. «Найти только новые» останавливается на уже
   импортированной публикации; «Проверить все сохранённые» проходит весь список.
   «Проверить только последние» дополнительно ограничивает число результатов.
3. При необходимости включите выбор папок и «Остановиться по ссылке».
   Поиск прекращается на первой достигнутой границе; сама граница исключается.
4. Нажмите «Начать поиск». Выберите папки, затем публикации и элементы каруселей.
5. Настройте имена и описания. Запустите импорт и выберите папку Eagle.
6. Дождитесь итога. При остановке повторно откройте плагин и используйте
   предложенное восстановление незавершённого задания.

Режим «Из архива» для Instagram/Pinterest/Threads принимает поддерживаемые ZIP/JSON/HTML.
Для Threads проверен настоящий экспорт Meta: полный ZIP читает только
`saved_threads.json`. Лайки, собственные публикации и данные профиля из этого
ZIP не добавляются в сохранёнки. Можно также выбрать отдельный JSON или HTML.
В Центре аккаунтов Meta выберите профиль Threads, категорию «Threads» и JSON.
Списки сохранёнок содержат ссылки; для получения медиа нужен выбранный профиль
браузера с выполненным входом в Threads.
Для Behance, Vimeo, X, Dribbble и Layers совместимый архив сохранённого не подтверждён, поэтому этот режим скрыт.
Исходный архив не изменяется. Архивы, содержащие только ссылки, требуют сети
и, при необходимости, выбранной браузерной авторизации.

## Особенности источников

- Instagram и Pinterest: сохранённые, поддерживаемые коллекции и архивы.
- Behance: доски настроения, ссылки, отдельные блоки и целые .rscase.
  Для просмотра целого кейса установите ReferenceCanvas отдельно.
- Vimeo: по умолчанию Favorites; через выбор папок — доступные Watch Later
  и Showcases. Favorites и понравившиеся могут совпадать.
- X: Bookmarks, доступные папки закладок и отдельная лента понравившихся.
  Доступ к папкам зависит от возможностей аккаунта.
- Dribbble и Layers: по умолчанию все сохранённые коллекции; при выборе папок —
  выбранные. Лайки находятся в отдельном сценарии. У Dribbble несколько медиа,
  следующий текст относится к предыдущему блоку; у Layers одно медиа на работу.
  Общий N без выбора папок действует в порядке коллекций платформы.
- Threads: сохранённые, лайки, ссылки и поддерживаемый архив Meta. Фото, видео,
  смешанные карусели; текст без медиа пропускается и отмечается в журнале.
  Ответы и последующие посты беседы не объединяются в карусель. Папок нет.

## Компоненты и данные

Подготовка движка использует подходящий Python 3.10+ с pip либо устанавливает
отдельный переносимый Python от Astral с проверкой закреплённого SHA-256.
Затем устанавливаются gallery-dl, yt-dlp, curl_cffi, pycryptodomex и FFmpeg
из настроенного индекса пакетов (обычно PyPI). Загрузка начинается только
по кнопке; системный PATH, реестр и установленный Python не меняются.

Авторизация берётся из выбранного браузера. Плагин не запрашивает пароль.
Временные cookies защищены до записи, проверяются после и удаляются после
использования. Снимки остановленных процессов очищаются при следующем запуске.
Системная защита браузера может не позволить прочитать сессию.

Настройки, история, незавершённые задания, отдельный Python и компоненты хранятся
в `.reference-sync` домашней папки. Удаление плагина не удаляет эту рабочую папку.
Личные архивы и исходные данные браузера остаются без изменений. Аналитики
и передачи данных разработчику нет; запросы идут нужным сайтам, медиасервисам,
источникам установки компонентов и локальному Eagle API.

После сборки и проверки целого Behance-кейса его временные исходные блоки
удаляются; блоки, выбранные для отдельного добавления, сохраняются. Готовый
кейс остаётся до подтверждённого импорта в Eagle. На скачивание, сборку
и копирование нужно дополнительное свободное место. Ошибки не дают считать
неполный кейс полностью импортированным; доступно восстановление задания.

## Если возникла ошибка

Проверьте вход в нужный аккаунт и выбранный профиль браузера. При ограничении
запросов подождите и повторите с меньшей скоростью. Доступность медиа зависит
от сайта, прав аккаунта и сети; архив со ссылками не обходит ограничения.
Технический журнал показывает причину ошибки. Не публикуйте личные журналы,
архивы и рабочую папку без проверки содержимого.
