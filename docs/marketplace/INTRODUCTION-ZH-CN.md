# ReferenceSync

将选中的帖子和媒体导入 Eagle 素材库。先查看搜索结果，再选择需要导入的内容，并保留来源链接和描述，方便整理参考素材。

## 开始使用前

**请先自行安装 Python 3.10 或更高版本，再准备下载引擎。ReferenceSync 不会安装 Python。**

安装 Python 后，ReferenceSync 可以通过已有的 Python 安装或更新 gallery-dl。需要时，可在插件中准备 yt-dlp 和 FFmpeg 等视频组件。下载这些依赖项需要网络连接，并由您在插件中主动操作。

对于需要浏览器登录状态的来源，请先在受支持的浏览器中登录对应网站，然后在 ReferenceSync 中选择该浏览器及用户配置。插件不会索取您的账号密码。实际可用性取决于网站、账号访问权限以及浏览器的 Cookie 保护机制。

临时浏览器 Cookie 快照会写入仅供当前用户访问的目录，并在使用后删除。异常中断遗留的快照会在后续启动时清理；没有进程标识的旧快照会在 24 小时后清理。需要浏览器身份验证的归档帖子链接会经过验证，并使用 HTTPS。
